# Hyprland 0.57 Lua rescue (experimental)

**Status: unverified draft; not ready for daily use without testing.** This work is on the
`fix/hyprland-057-lua-recovery` branch. The original `.conf` configuration
files have deliberately not been edited or removed.

## Scope of first stage

`common/hyprland.lua` loads split modules from `~/.config/hypr/lua`.
Current modules provide initial versions of environment variables, settings,
decorations (with existing Wallust color files), animations, fallback monitor
configuration, keybindings, selected window rules, and startup programs.

This is **not a complete 1:1 conversion**. Not yet migrated/tested:
the remaining legacy keybinds, 119 window/layer rules, desktop/laptop Host.conf
profile distinctions, device-specific settings, generated monitor/workspace
rules, script calls that use legacy `hyprctl dispatch` syntax, and runtime
behavior such as Waybar, Quickshell, wallpapers, startup, and locking.
Some settings or Lua APIs may need further correction for Hyprland 0.57.1.

## Safety

Do not run `set-hypr-profile.sh` to switch to Lua; that legacy installer
rebuilds the active profile tree and modifies PAM faillock by default.
This branch does not change that installer or its `.conf` guard.

The opt-in `stage-lua-recovery.sh` operates only on an **existing** managed
`~/.config/hypr` tree; it does not replace that directory or touch the repo's
original `.conf` files. It refuses to overwrite a custom Lua entrypoint or
existing `lua/` directory. It preserves the generated example before
switching to this branch's source and provides explicit rollback. Backups live
outside the repo in `~/.local/state/jakoolit-lua-recovery/` unless
`XDG_STATE_HOME` overrides the location.

Only after checking out the branch in the original local repo:
```bash
./jakoolithyprl/stage-lua-recovery.sh --check
# After reviewing files, with a TTY available for emergency access:
./jakoolithyprl/stage-lua-recovery.sh --activate
hyprctl reload
hyprctl configerrors
```

To revert the Lua entrypoint, **from a usable terminal or TTY**:
```bash
./jakoolithyprl/stage-lua-recovery.sh --restore
```

Restoring the previous autogenerated Lua file will **not** make the old
`.conf` settings load on Hyprland 0.57. This is a rollback of file changes,
not a complete working old-desktop rollback.

Do not merge or deploy without actual Hyprland 0.57 testing. Keep a working
TTY and independent terminal accessible throughout recovery. See issue #1.
